# 음성 슬라이드 — 전기 에너지의 생산

교실 노트북의 **크롬**에서 여는 21장 슬라이드 뷰어입니다. 페이지가 Web Speech API로 스피커에서 나오는 선생님 목소리를 듣고, 말한 명령에 맞춰 장을 넘기거나 정답을 공개합니다. ElevenLabs나 별도 AI 키는 쓰지 않습니다.

**주소:** https://truth42order.github.io/voice-slides/

## 쓰는 법

1. 크롬으로 위 주소를 연다. **수업 시작**을 누르고 마이크를 허용한다.
2. 전체화면(F)을 켠 뒤, 음성 통화 소리가 이 노트북 스피커로 나오게 한다.
3. 선생님이 「다음 슬라이드」, 「14번으로」, 「정답 공개」라고 말하면 페이지가 반응한다. 인식이 안 되면 키보드로도 된다.

## 음성 명령

| 동작 | 말하면 되는 말 |
|---|---|
| 다음 | 다음 슬라이드, 다음 장, 넘겨 |
| 이전 | 이전 슬라이드, 앞 장, 뒤로 |
| N번으로 | 14번 슬라이드, 14번으로, 14쪽, 십사번으로, 열네 번으로 |
| 정답 한 칸 | 정답 공개, 답 보여줘 |
| 첫 장 | 처음으로 |

10장과 14장은 수업 영상과 같은 순서로 정답이 가려져 있고, 「정답 공개」를 말할 때마다 다음 칸이 열립니다.

## 키보드

← → 또는 Space, 숫자+Enter, R(정답), F(전체화면), H(상태창 숨김), Home(처음으로)

## 시험

```bash
node test-commands.js
```

수업 대본에 나오는 「다음 장에서」, 「뒤로 돌려서」, 「21번 정리 슬라이드」, 「이번엔」, 「학습지 48쪽」 같은 문장은 명령으로 보지 않습니다.
